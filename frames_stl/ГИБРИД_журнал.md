# Гибрид Nova SM3 + robjk — журнал решений

Сцена: `Hybrid_Nova_robjk.blend`. Оси сцены: X — вбок, Y — вперёд, Z — вверх; ноль по Z — на осях плеч.

## Зафиксировано
- Корпус: Nova SM3 v5.2b, стоковый, без переделок рамы.
- Ноги: robjk (thing:4937631) + недостающие детали Kubina из `Kubina_leg_parts/` (накладки колена — длинные, `*_long_v4`).
- Выборка в раме Nova (`HYB_Nova_*_KubinaRelief.stl`) НЕ нужна: блок плеча robjk у́же стокового.
- Положения деталей взяты из авторских сборок: корпус — STEP Nova, нога — FreeCAD Kubina.

## Пересечения (плечо −45…+45°)
- Плечо, крышка robjk, верхние крышки Nova — чисто.
- Передние ноги: при сведении внутрь ≥25° бедро задевает `SM3_Cover_BottomFront`.

## Шаг 1. Посадка качалки плеча — в работе
- Блок robjk упирается буртиком Ø8 во внутреннее кольцо подшипника 625ZZ; в сцене блок посажен вплотную к пластине с подшипником.
- От плоскости ушей сервы в блоке до дна кармана качалки в пластине Nova: 18,24 мм (до поверхности пластины 14,5 мм, карман Ø20,1 глубиной 3,74 мм).
- Нужно с живой сервы QY3240MG: размер «низ ушей → наружная плоскость надетой дисковой качалки». Если ≤18,2 — собирается; если больше — будет распор.
