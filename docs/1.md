#  🧠 ЧАСТЬ 2. УСТАНОВКА ROS Kinetic НА RASPBERRY PI 3 / 4

---

## 🔹 1. Подготовка SD-карты и системы

1. Скачай **Ubuntu MATE 16.04.2 for Raspberry Pi 3/4**
   🔗 [https://releases.ubuntu-mate.org/16.04.2/raspberry-pi/](https://releases.ubuntu-mate.org/16.04.2/raspberry-pi/)

2. Запиши образ через **Raspberry Pi Imager** или `balenaEtcher`.

3. Подключи монитор, клавиатуру и Wi-Fi/Ethernet.

4. После загрузки обнови систему:

   ```bash
   sudo apt update && sudo apt upgrade -y
   sudo reboot
   ```

---

## 🔹 2. Установка зависимостей

```bash
sudo apt install -y dirmngr gnupg2 lsb-release
```

---

## 🔹 3. Добавление репозиториев ROS

```bash
sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'
sudo apt-key adv --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654
sudo apt update
```

---

## 🔹 4. Установка ROS Kinetic

Минимальная версия (для SpotMicro хватит):

```bash
sudo apt install -y ros-kinetic-ros-base
```

Если есть место (рекомендуется):

```bash
sudo apt install -y ros-kinetic-desktop-full
```

---

## 🔹 5. Настройка окружения

Добавляем ROS в `~/.bashrc`:

```bash
echo "source /opt/ros/kinetic/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

Проверим:

```bash
roscore
```

Если видишь “started core service” — всё работает ✅

---

## 🔹 6. Установка инструментов сборки ROS

```bash
sudo apt install -y python-rosdep python-rosinstall python-rosinstall-generator python-wstool build-essential cmake git
sudo rosdep init
rosdep update
```

---

## 🔹 7. Создание рабочего пространства

```bash
mkdir -p ~/catkin_ws/src
cd ~/catkin_ws/
catkin_make
echo "source ~/catkin_ws/devel/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

Проверим:

```bash
echo $ROS_PACKAGE_PATH
```

Должен включать `/home/ubuntu/catkin_ws/src`.

---

## 🔹 8. Клонирование и сборка SpotMicro

```bash
cd ~/catkin_ws/src
git clone https://github.com/mike4192/spotMicro.git
cd ~/catkin_ws
rosdep install --from-paths src --ignore-src -r -y
catkin_make
```

Если `ros-i2cpwmboard` не установлен, добавь вручную:

```bash
cd ~/catkin_ws/src
git clone https://gitlab.com/ksumit1208/ros-i2cpwmboard.git
cd ~/catkin_ws && catkin_make
```

---

## 🔹 9. Настройка PCA9685 (I²C)

Проверим, что модуль доступен:

```bash
sudo apt install -y i2c-tools
sudo i2cdetect -y 1
```

Если видишь адрес **0x40**, значит плата PCA9685 найдена ✅

Добавь пользователя в группу i2c:

```bash
sudo usermod -aG i2c $USER
```

и перезагрузи:

```bash
sudo reboot
```

---

## 🔹 10. Проверка ROS и модулей

После перезагрузки:

```bash
roscore &
rosrun ros_i2cpwm_board servo_test.py
```

Если серво реагирует — всё подключено корректно ⚙️
