# 🧠 ЧАСТЬ 3. ТЕСТИРОВАНИЕ И КАЛИБРОВКА SPOTMICRO

---

## ⚙️ 1. Проверка аппаратной части

### 🧩 Подключение PCA9685

* Подключи модуль PCA9685 к Raspberry Pi по шине I²C:

  ```
  VCC → 5 V
  GND → GND
  SDA → GPIO 2 (3)
  SCL → GPIO 3 (5)
  ```
* Подключи сервы (например MG996R или DS3218) к выходам 0–11 PCA9685.
* Запусти проверку:

  ```bash
  sudo i2cdetect -y 1
  ```

  → должен появиться адрес **0x40**.
  Если нет — проверь питание и пайку.

## 🧩 2. Проверка работы драйвера PCA9685 (ROS i2cpwmboard)

```bash
cd ~/catkin_ws
source devel/setup.bash
rosrun ros_i2cpwm_board servo_test.py
```

→ Один из сервоприводов должен слегка провернуться.
Если не реагирует:

```bash
sudo adduser $USER i2c
sudo reboot
```

## 🧱 3. Проверка базового ROS

На Raspberry Pi:

```bash
roscore
```

В другом окне (или новой SSH-сессии):

```bash
rosrun rospy_tutorials listener.py
```

Если выводится `I heard hello world` — ROS-ноды взаимодействуют корректно.

## 🦾 4. Калибровка сервоприводов SpotMicro

1. Убедись, что робот стоит на ровной поверхности и сервы подключены правильно.
2. Запусти специальный узел калибровки:

   ```bash
   roslaunch spot_micro_motion_cmd calibrate_servos.launch
   ```
3. Робот примет “нулевую” позу — ноги прямо.
4. При необходимости поправь физическое положение рычагов, чтобы при нуле оси были выровнены.
5. Сохрани параметры в `spot_config.yaml`.

---

## ⚙️ 5. Проверка топиков ROS

Посмотреть активные топики:

```bash
rostopic list
```

Ты должен видеть:

```
/spot_micro/leg_positions
/spot_micro/joint_states
/spot_micro/cmd_vel
/i2cpwm_board/servo_positions
```

Проверить значения:

```bash
rostopic echo /spot_micro/joint_states
```

→ Появятся углы в радианах.

---

## 🧭 6. Тест виртуального движения (без физики)

Если хочешь только проверить вычисления:

```bash
roslaunch spot_micro_motion_cmd motion_cmd.launch sim:=true
```

RViz отобразит виртуального робота, который двигается согласно планировщику.

---

## 🕹️ 7. Управление с клавиатуры

Запуск:

```bash
roslaunch spot_micro_keyboard_command keyboard_command.launch
```

Клавиши:

| Клавиша   | Действие       |
| --------- | -------------- |
| `w` / `s` | Вперёд / назад |
| `a` / `d` | Поворот        |
| `r` / `f` | Вверх / вниз   |
| `space`   | Остановить     |
| `q`       | Выйти          |

💡 Все команды передаются по топику `/spot_micro/cmd_vel`.

---

## 📊 8. Мониторинг состояния

Открой RViz:

```bash
rosrun rviz rviz
```

Добавь дисплей:

* `RobotModel` → `/robot_description`
* `TF` — кадры координат
* `JointState` — движения суставов

Запусти также графическую утилиту:

```bash
rqt_graph
```

→ увидишь связи между узлами (`keyboard_cmd` → `motion_cmd` → `i2cpwmboard`).

---

## 🧩 9. Проверка походки

После базовой калибровки и реакции сервоприводов можно проверить ходьбу:

```bash
roslaunch spot_micro_motion_cmd walk.launch
```

Робот должен делать медленные шаги — убедись, что ноги не клинят и центровка сохранена.

---

## ⚠️ 10. Диагностика типичных ошибок

| Симптом                  | Причина                                | Решение                                          |
| ------------------------ | -------------------------------------- | ------------------------------------------------ |
| Сервы не двигаются       | Неправильный адрес I²C или нет доступа | Проверь `i2cdetect`, добавь в группу `i2c`       |
| Робот дрожит / дёргается | Нестабильное питание                   | Используй BEC 5 V ≥ 5 A или отдельные источники  |
| Ошибки в launch-файлах   | Неверные пути в `.bashrc`              | Проверь `source ~/catkin_ws/devel/setup.bash`    |
| RViz не открывается      | DISPLAY не задан                       | Проверь `export DISPLAY=<IP_Windows>:0` и VcXsrv |
