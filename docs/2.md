# 🧭 ЧАСТЬ 2. Настройка Windows как пульта (SSH + VcXsrv + ROS визуализация)

---

## 💡 Цель

Ты получишь следующую схему:

```
🪟 Windows ПК (RViz, rqt, клавиатура)
      ↕ (Wi-Fi / Ethernet)
🍓 Raspberry Pi 3/4 (ROS, PCA9685, серво)
```

---

## 🔹 1. Настрой Raspberry Pi для удалённого доступа

Убедись, что на Pi установлен SSH:

```bash
sudo systemctl enable ssh
sudo systemctl start ssh
```

Проверь IP-адрес:

```bash
hostname -I
```

(например `192.168.1.42`)

---

## 🔹 2. Установи VcXsrv на Windows

🔗 Скачай: [https://sourceforge.net/projects/vcxsrv/](https://sourceforge.net/projects/vcxsrv/)

Установка:

* При первом запуске появится **XLaunch** → выбери:

  1. ✅ Multiple windows
  2. ✅ Start no client
  3. ✅ Disable access control
  4. Finish

После запуска — иконка VcXsrv появится в трее (с крестиком X).
Окно не нужно — просто оставь его запущенным.

---

## 🔹 3. Узнай IP Windows

На Windows в PowerShell:

```powershell
ipconfig
```

Найди IPv4-адрес, например `192.168.1.105`.

---

## 🔹 4. Подключись с Windows к Raspberry Pi

В PowerShell:

```powershell
ssh ubuntu@192.168.1.42
```

(замени IP на свой Pi)
Пароль — `ubuntu` (или свой).

---

## 🔹 5. Разреши передачу графики на Windows

В открывшейся SSH-сессии (на Pi):

```bash
export DISPLAY=192.168.1.105:0
```

(где `192.168.1.105` — IP твоего Windows)

> 💡 Чтобы не вводить каждый раз, можно добавить в конец файла:
>
> ```bash
> echo "export DISPLAY=192.168.1.105:0" >> ~/.bashrc
> ```

---

## 🔹 6. Проверь X11-соединение

На Raspberry Pi:

```bash
xclock
```

🟢 Если появилось окно с часами на Windows — всё работает!
(Если нет → проверь, что VcXsrv запущен и не блокируется антивирусом/брандмауэром.)

---

## 🔹 7. Запуск визуализации ROS

Теперь можно открывать интерфейсы ROS на Windows:

### RViz

```bash
rosrun rviz rviz
```

### rqt (графики, топики)

```bash
rqt
```

### Граф ROS-нод

```bash
rqt_graph
```

Все GUI окна будут появляться **на твоем Windows**,
но исполняться физически на Raspberry Pi.

---

## 🔹 8. Запуск SpotMicro

В ROS-пространстве (на Pi):

```bash
cd ~/catkin_ws
source devel/setup.bash
roslaunch spot_micro_keyboard_command keyboard_command.launch
```

Теперь:

* RViz покажет 3D-модель робота
* ты можешь управлять им с клавиатуры Windows (в активном терминале)
* ROS-ноды работают на Pi, а визуализация — на Windows

---

## 🔹 9. (Опционально) RViz + Motion совместно

1. Запусти ROS-core:

   ```bash
   roscore
   ```
2. В другом окне:

   ```bash
   roslaunch spot_micro_motion_cmd motion_cmd.launch
   ```
3. В третьем:

   ```bash
   rviz
   ```

→ Увидишь, как робот двигается в 3D-пространстве.

---

## 🧩 Проверка соединения

Можно убедиться, что оба устройства “видят” друг друга:

```bash
ping 192.168.1.105      # с Pi на Windows
ping 192.168.1.42       # с Windows на Pi
```

---

## ⚙️ Если окно RViz не появляется

1. Проверь, что VcXsrv **запущен от имени администратора**.
2. Убедись, что IP Windows верный и совпадает с `DISPLAY`.
3. Временно отключи “Брандмауэр Защитника Windows” для входящих соединений X11.
