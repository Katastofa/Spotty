# hostcheck — офлайн-проверка прошивки

Собирает `../gait_test/gait_test.ino` обычным `g++` и гоняет по нему
регрессию. **Копии кода здесь нет**: заглушки подменяют только железо
(`Arduino.h`, `Wire.h`, `Adafruit_PWMServoDriver.h`), вся арифметика —
настоящая, из того файла, который заливается в ESP32-S3.

```
./build.sh            ворота регрессии
./build.sh preview    что напечатает 'p' на роботе, без подачи питания
./build.sh tune       перебор параметров под лимит по скорости сустава
```

Сборка идёт в `/tmp`: в папку проекта не пишется ни одного файла.

## Ворота

| | что доказывает |
|---|---|
| **A** | `legIK` против прямой задачи: точка → углы → точка, невязка < 0.01 мм |
| **B** | угловая модель (`reachOf`/`alphaOf`/`kneeForReach`, в единицах бедра) и `legIK` (в мм) дают одни и те же углы — это одна и та же нога |
| **B2** | чем траектории всё же отличаются, с числом и причиной |
| **C** | стопа в переносе отрывается и садится без рывка |
| **D** | недостижимая точка поднимает `ikFail`, а не проглатывается |
| **E** | поза (`n`) и походка (`w`) стыкуются: расхождение 0.00000° |

## Что уже показал стенд

- невязка `legIK` — **0.000175 мм** на 2378 точках рабочей области;
- расхождение двух моделей ноги — **0.00003°**, то есть они тождественны;
- расхождение траекторий опоры — **0.23 мм**, и оно объяснено: угловой
  движок ведёт линейно УГОЛ ноги, декартов — САМУ СТОПУ. `tan(12·s) ≠
  tan(12)·s`. В опоре стопа стоит на земле, значит постоянной должна быть
  скорость стопы, а не угла: угловой движок разгоняет и тормозит корпус
  примерно на 1% за шаг, декартов — нет;
- поза и походка сходятся в **0.00000°**; до правки `setTargetsToPose()`
  расхождение было **4.2°** — робот прыгал бы на столько за один тик при
  переходе от `n` к `w`;
- умолчания порта у автора (перенос 200…400 мс) требуют **305…375 °/с** по
  колену на нашем железе при разрешённых 100. Умолчания подобраны заново:
  `P 30, C 15, V 60, W 900` дают период 1900 мс, duty 0.53 и пик **80 °/с** —
  тот же режим, в котором угловой движок отработал прогон 29.08.

## websyntax.sh (2026-09-28)

`./websyntax.sh` — `g++ -fsyntax-only` всего `gait_test.ino` с `SPOTTY_WEB 1`
на заглушках из `webstub/` (WiFi, WebServer, mDNS, FreeRTOS, Print, String).
`build.sh` веб-часть не собирает (`SPOTTY_WEB 0`), это — единственная проверка
`spotty_web.h` без ESP32-тулчейна. Поведение не проверяет, сборку под ESP32 не заменяет.
Для неё в `Arduino.h` добавлен `HostSerial::write(buf, n)` — на `build.sh` не влияет.
