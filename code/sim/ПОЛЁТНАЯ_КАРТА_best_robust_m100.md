# ПОЛЁТНАЯ КАРТА — набор `best_robust_m100`

Сгенерировано `export_set.py` из `best_robust_m100.json`.
Числа ниже посчитаны ПРОШИВКОЙ, а не пересказаны.

## 1. Что это за набор

| параметр | значение | команда | что значит |
|---|---|---|---|
| движок | декартов | `G 1` | декартов движок (мм), а не угловой |
| `height` | 136.84 | `H 137` | глубина стопы под осью хипа |
| `span` | 39.08 | `P 39` | полушаг: полный шаг вдвое больше |
| `lift` | 14.76 | `C 15` | подъём стопы в переносе |
| `vel` | 68.10 | `V 68` | скорость корпуса; из неё выводится опора |
| `swing` | 1073.48 | `W 1073` | время переноса; вместе с V даёт duty и период |
| `shiftgain` | 1.23 | `B 1.23` | перенос корпуса по фазе, доля расчётной амплитуды |
| `maxrate` | 100.00 | `m 100` | предел скорости сустава |

Походка **walk**, период **2221 мс**, duty **0.52** (опора 52 % цикла).

## 2. Чем этот набор проверен

Прогнан по **13 мирам** с разными ПРИНЯТЫМИ массами, ЦТ, трением,
жёсткостью контура и латентностью — устоял в **11**.

* путь: медиана **+652 мм**, худший **+82 мм**
* запас устойчивости: медиана **13.7 мм**
* **упал** в мирах: hip_mass_kg=0.105, thigh_mass_kg=0.126, shank_mass_kg=0.035; foot_friction=1.2, ground_friction=1.2

Пик по суставу **93 °/с** при разрешённых **100**, ограничитель не вмешивается.

Перенос корпуса: амплитуда из геометрии **12.47 мм**, доля **1.23** → **+15.34 мм**.

Продольная база: **прошивка, ИЗМЕРЕНО (M4)**.

> **Это НЕ рекомендация для пола.** Набор найден в модели, у которой
> массы, ЦТ и модель серво — ПРИНЯТЫ, а не измерены. Первый прогон
> только на подвесе, по `SAFETY.md`.

## 3. Порядок ввода

```
G 1
H 137
P 39
C 15
V 68
W 1073
B 1.23
m 100
p
```

Готовый файл для вставки целиком: `set_best_robust_m100.txt`.

Порядок не косметический: `H`, `P`, `C`, `V`, `W`, `X`, `B` в
декартовом режиме имеют смысл только после `G 1`, а каждая смена
параметра сама гоняет предполётную. Последняя `p` — контрольная.

## 4. Что обязано напечатать `p`

* `Предполётная проверка пройдена (пределы).` — иначе НЕ ПУСКАТЬ;
* пик требуемой скорости **93 °/с** — если робот показал другое
  число, значит применились не те параметры;
* строку переноса корпуса с амплитудой **15.34 мм**;
* ни одного `[!!]`.

## 5. Прогон и запись

```
n          выйти в позу (движение! робот должен быть на подвесе)
w 4        пойти
x          остановить в любой момент
```

**Сохраните вывод терминала в файл целиком.** Он нужен для сверки:

```
python compare_real.py <лог.txt> --params results/best_robust_m100.json
```

Сверка покажет, совпали ли углы, которые робот РЕАЛЬНО выдал, с теми,
которые посчитала модель. Расхождение означает, что на роботе
применилось не то, что в модели, — и до выяснения дальше идти нельзя.

## 6. Если пойдёт не так

| что видно | что это | что делать |
|---|---|---|
| `[!!] ОТКАЗ IK на ходу` | заказанная точка недостижима | `x`, проверить `H` и `P` |
| `АВАРИЙНЫЙ СТОП` по пределу | сустав упёрся в жёсткий предел | `x`, смотреть, какой канал, сверить нули |
| серво гудят, ноги отстают | не хватает момента или скорости | `x`, снизить `V`, поднять `W` |
| робот валится на борт | запас устойчивости ушёл | `x`, поднять `B`, снизить `H` |
| сверка даёт большое расхождение | применились не те параметры или нули | не гонять дальше, разбираться |
